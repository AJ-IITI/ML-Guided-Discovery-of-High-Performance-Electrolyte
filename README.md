# ML-guided discovery of high-performance electrolytes

This repository studies the ionic conductivity of electrolyte formulations using records from the Open Electrolyte Database (OEDB). The research notebooks and historical results remain in `notebooks/` and `outputs/`.

On the **website-mvp** branch, the [research portal](website/README.md) lets you explore the repository dataset, inspect the model methods and validate a formulation at 298 K. Phase 1 runs locally on a CPU. The prediction models are not loaded.
