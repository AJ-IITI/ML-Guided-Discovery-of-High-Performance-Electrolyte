About this platform

A research interface for electrolyte data exploration and conductivity prediction.

DATA

Open Electrolyte Database

The prototype uses the OEDB computational dataset included with this research repository. Dataset version and record count are reported by the API.

Visit OEDB ↗
MODEL 01

HGB-SVR

A conventional tabular machine-learning model. The original trained estimator and preprocessing pipeline must be connected without changing feature construction.

MODEL 02

SMI-TED

A molecular foundation model combined with numerical formulation features. The original tokenizer, fine-tuned checkpoint and 47-feature pipeline must be preserved.

OEDB data are distributed under CC BY 4.0. Please cite the original OEDB publication when using the data.
